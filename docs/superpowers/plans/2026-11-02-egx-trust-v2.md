# EGX Trust Indicator v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Change the win definition to net R > 0 and add three optional hard filters (Require Index Up, Weekly Trend, ADX), so v2 can be tuned and validated profit-first.
**Architecture:** Edits only in `src/egx-trust-indicator.pine` plus both READMEs. No new files.
**Tech Stack:** Pine Script v6.
**Spec:** `docs/superpowers/specs/2026-11-02-egx-trust-v2-design.md` (and v1 spec for everything unchanged)

## Global Constraints
- Every `ta.*` and `request.security` call is unconditional and at global scope.
- No field of a possibly-`na` UDT is read through an `and` chain.
- UDT fields mutate only inside functions that receive the object.
- Number format `"0.00"`, never `"#.00"`. Stay under 64 plots.
- Filters default **off**. Turning them all off must reproduce v1 trade selection exactly; only the win counting changes.
- README.md and README.ar.md change in the same task.

## Review Focus
1. Weekly request repainting: it must use `close[1]` and `sma[1]` with `lookahead_on`, and never `lookahead_on` on the current bar's values.
2. On weekly or monthly charts, the weekly filter must pass rather than request a lower timeframe.
3. The win definition must be identical everywhere: stats, bands, track record, label colour, log field.

```pine
// Weekly trend from the last completed week only: close[1] with lookahead_on is the standard
// non-repainting way to read a higher timeframe.
[wkClose, wkMa] = request.security(syminfo.tickerid, "W", [close[1], ta.sma(close, weeklyLen)[1]], lookahead = barmerge.lookahead_on)
weeklyApplies   = timeframe.in_seconds(timeframe.period) < timeframe.in_seconds("W")
weeklyUp        = not weeklyApplies or (not na(wkMa) and wkClose > wkMa)
[diPlus, diMinus, adxVal] = ta.dmi(adxLen, adxLen)
gateFilters = (not requireIdxUp or regime == 1) and (not useWeekly or weeklyUp) and (not useAdx or (not na(adxVal) and adxVal >= adxMin))
```
